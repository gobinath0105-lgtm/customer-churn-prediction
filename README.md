# Customer Churn Prediction

## 📌 Project Overview

This is my second Machine Learning project.

The goal of this project is to predict whether a customer will **churn (leave the company)** or **stay** based on customer information.

This is a **binary classification** problem.

- `0` → Customer stayed
- `1` → Customer churned

## 📊 Dataset

The dataset contains 500 customer records.

### Numerical Features
- Age
- Tenure Months
- Monthly Charges
- Support Calls

### Categorical Features
- Contract
- Internet Service
- Payment Method

### Target
- Churn

## 🔍 Project Workflow

1. Load and understand the dataset
2. Check missing and duplicate values
3. Perform Exploratory Data Analysis (EDA)
4. Analyze numerical features
5. Analyze categorical features
6. Encode categorical features
7. Separate features (`X`) and target (`y`)
8. Split data into training and testing sets
9. Train Logistic Regression
10. Evaluate the model using:
   - Accuracy
   - Confusion Matrix
   - Precision
   - Recall
   - F1-score
11. Train Decision Tree
12. Train Random Forest
13. Compare the models

## 🤖 Machine Learning Models
